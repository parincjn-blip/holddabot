# Disbot — สรุปงานบอท Discord

จัดทำวันที่ 6 ตุลาคม 2026 จากโค้ดในโปรเจกต์และบันทึก deployment วันที่ 4 ตุลาคม 2026

## ภาพรวม

บอทสำหรับดูแลสมาชิก เก็บ Chat/Talk XP เลื่อนยศ จัด Giveaway และประกาศสตรีม รองรับหลายเซิร์ฟเวอร์ด้วยบอทหนึ่งชุด การตั้งค่าและข้อมูลแยกตาม `guild_id` ใน PostgreSQL ไม่ต้องรันบอทแยกต่อเซิร์ฟเวอร์

ระบบใช้ TypeScript, Node.js 22+, discord.js, PostgreSQL และ @napi-rs/canvas สำหรับการ์ดสมาชิก n8n สามารถเชื่อมฐานข้อมูลด้วยบัญชีอ่านอย่างเดียวเพื่อทำรายงานเพิ่มเติม โดยไม่ต้องรับ Bot Token

## ฟีเจอร์ที่ทำแล้ว

| ระบบ | สิ่งที่รองรับ |
| --- | --- |
| สมาชิกเข้า–ออก | บันทึกเหตุการณ์และส่งประกาศ พร้อมรูปสมาชิก ชื่อ และอายุบัญชีสำหรับสมาชิกใหม่ |
| Welcome Card | ใช้ภาพพื้นหลังต้นฉบับ ใส่รูปสมาชิก Display Name และจำนวนสมาชิก |
| Voice เข้า–ออก | แจ้งในแชทของห้องเสียงนั้น หรือห้องรวมที่ตั้งไว้ ไม่แท็กสมาชิก |
| Chat Level | XP จากข้อความ พร้อม cooldown, ความยาวขั้นต่ำ, ป้องกันข้อความซ้ำ และโควตาต่อวัน |
| Talk Level | XP จากเวลาในห้องเสียง ตรวจ AFK, จำนวนคนจริง และสถานะ deafen |
| Rank Card | แสดงรูปสมาชิก Display Name, Chat/Talk Level, อันดับ และความคืบหน้า XP |
| Level Up | ประกาศทุกครั้งที่เพิ่มเลเวล: หัวข้อ → ภาพ → footer แยก Chat/Talk ไม่มี Container |
| เลื่อน Role | เลือกยศสูงสุดที่ผ่านเกณฑ์ เพิ่มยศใหม่ก่อนถอนยศเก่าที่บอทจัดการ ไม่แตะ Role อื่น |
| การ์ดได้รับยศ | ชุดภาพต้นฉบับ 9 ยศ เติมรูปโปรไฟล์และ Display Name ซ้อน overlay เดิม ไม่เพิ่มเลเวลหรือ XP ในภาพ |
| Giveaway | กดก่อนได้ก่อน หรือเข้าร่วมแล้วสุ่ม กำหนดจำนวนผู้ชนะ เวลา และเลเวลขั้นต่ำได้ |
| โบนัสสตรีม | ผู้แชร์จอ/Go Live รับ Talk XP ×3 เมื่อผ่านเงื่อนไขเดิมและเปิดฟีเจอร์ |
| ประกาศสตรีม | ส่งเฉพาะตอนเริ่ม มี Display Name, ห้องแบบไม่แท็ก, Role แจ้งเตือน, รูปสมาชิก, banner และปุ่มลิงก์ตรง |
| Role ผู้สตรีม | มอบระหว่างสตรีม ถอนเมื่อหยุด/ออกห้อง และกู้คืนสถานะหลังรีสตาร์ตจาก ownership ledger |
| ตั้งค่าจาก Discord | เลือกห้อง Role เกณฑ์เลเวล AFK และเปิด–ปิดฟีเจอร์แยกต่อเซิร์ฟเวอร์ |
| Template Studio | เว็บแก้ข้อความ 8 ประเภท แยกเซิร์ฟเวอร์ มีพรีวิว ประวัติ และย้อนคืนค่า ผ่าน Discord OAuth |

หน้าเว็บได้รับยศมีตัวเลือกดูภาพทั้ง 9 ยศ (ไม่เปลี่ยนยศจริง) ใช้สคริปต์เรนเดอร์เดียวกับบอท ค่าเริ่มต้นส่งเฉพาะการ์ด ข้อความประกอบนอกภาพเป็นตัวเลือก ไม่เปิดให้เปลี่ยนภาพต้นฉบับ

เซิร์ฟเวอร์ใหม่เริ่มปิดทุกฟีเจอร์ ต้องตั้งข้อมูลที่จำเป็นก่อนเปิด เซิร์ฟเวอร์เดิมนำค่า legacy จาก environment เข้าฐานข้อมูลครั้งเดียว การรีสตาร์ตไม่ล้างค่า

## กติกา XP ปัจจุบัน

| รายการ | Chat | Talk |
| --- | --- | --- |
| เลเวลสูงสุด | 100 | 30 |
| XP สะสมที่เลเวล L | `12 × L²` | `32 × L²` |
| XP ถึงเลเวลสูงสุด | 120,000 | 28,800 |
| XP ต่อครั้ง | 5–10 ต่อข้อความที่ผ่านเงื่อนไข | 1 ต่อนาทีที่ผ่านเงื่อนไข |
| โควตาต่อวัน | 1,000 | 240 รวมโบนัสสตรีมแล้ว |
| เวลาขั้นต่ำถึงสูงสุด | 120 วันเมื่อเริ่มจาก 0 และได้เต็มโควตาทุกวัน | 120 วันเมื่อเริ่มจาก 0 และได้เต็มโควตาทุกวัน |

- Chat: ข้อความอย่างน้อย 8 ตัวอักษร, cooldown 60 วินาที, ช่วงตรวจข้อความซ้ำ 5 นาที
- Talk: ต้องมีคนจริงอย่างน้อย 2 คน ไม่ใช่ Bot และไม่อยู่ห้อง AFK
- Server-deafen ไม่รับ Talk XP; self-deafen หยุดรับหลังตรวจพบต่อเนื่อง 10 นาที
- เปิด `stream_xp` แล้วผู้สตรีมได้ 3 XP/นาที ผู้ชมไม่ได้โบนัส เวลาที่บันทึกยังเพิ่มเพียง 1 นาทีต่อรอบ
- โควตารายวันใช้ timezone ที่ตั้งไว้ ค่าเริ่มต้น Asia/Bangkok

## คำสั่ง

สำหรับสมาชิก:

- `/level [member]` — ดูเลเวล XP และโควตาวันนี้
- `/member [member]` — ดูข้อมูลและสถานะสมาชิก
- `/rank [member]` — ดูการ์ดอันดับ
- `/leaderboard type:Chat Level|Talk Level` — ดูอันดับ

สำหรับผู้ดูแลตามสิทธิ์ที่ตั้งใน Discord:

- `/giveaway create` — สร้างกิจกรรม เลือกรางวัล รูปแบบ จำนวนผู้ชนะ และระยะเวลา
- `/giveaway status id:...` — ดูสถานะกิจกรรม
- `/giveaway end id:...` — ปิดกิจกรรมและเลือกผู้ชนะ
- `/feature status` — ดูการตั้งค่าและสถานะฟีเจอร์
- `/feature on|off feature:...` — เปิด–ปิดรายฟีเจอร์
- `/feature channel` และ `/feature clear-channel` — เลือกหรือล้างห้องประกาศ
- `/feature rank-set`, `/feature rank-remove`, `/feature ranks` — ตั้งและดูเกณฑ์ยศ
- `/feature afk-add`, `/feature afk-remove` — จัดการห้องที่ยกเว้น XP
- `/feature stream-role` — เลือก Role ที่แท็กในประกาศเริ่มสตรีม
- `/feature stream-active-role` — เลือก Role ที่มอบให้คนกำลังสตรีม

รวม 6 คำสั่งหลัก และ 12 subcommands ใน `/feature` มีสวิตช์ฟีเจอร์ 12 รายการ

**ข้อควรระวังเรื่องสิทธิ์:** ไม่มีรายการผู้ดูแลหรือ Role ผู้สั่ง hard-code ในบอท ผู้ดูแลต้องจำกัด `/feature` และ `/giveaway` ที่ Server Settings → Integrations ด้วยตนเอง

## Role และความปลอดภัยในการจัดการ

- เกณฑ์ยศเลือก Chat 0–100, Talk 0–30, AND/OR และ priority ได้; 0 หมายถึงไม่ใช้เกณฑ์นั้น ห้ามเป็น 0 ทั้งคู่
- รับยศสูงสุดที่ผ่านเพียงยศเดียว เพิ่มยศใหม่สำเร็จก่อนถอนยศเก่า และจัดการเฉพาะ Role ที่อยู่ในชุดเกณฑ์
- Role ของบอทต้องอยู่เหนือ Role เป้าหมาย พร้อมสิทธิ์ Manage Roles
- Role ผู้สตรีมต้องไม่เป็น Role เดียวกับยศเลเวลหรือ Role ของระบบ
- Role ผู้สตรีมถอนเฉพาะรายการที่บอทเป็นผู้มอบ บันทึกไว้ใน `stream_role_assignments`; Role ที่มีอยู่ก่อนจากการมอบเองไม่ถูกถอน
- ปิด `stream_role` หรือเปลี่ยน Role เป้าหมายแล้ว ระบบทำความสะอาด Role ที่บอทเคยมอบ
- Role แจ้งเตือนสตรีมกับ Role ผู้สตรีมเป็นคนละการตั้งค่า

## ข้อมูลและโครงสร้างโปรเจกต์

- `src/` — ตัวบอท คำสั่ง XP, Giveaway, Role, การ์ด และประกาศ
- `migrations/` — schema 001–006 รวมการตั้งค่าหลายเซิร์ฟเวอร์และ ownership ของ Role สตรีม
- `assets/` — ภาพเทมเพลตและฟอนต์ พร้อม license ฟอนต์
- `scripts/` — เครื่องมือ import และตั้งค่าเฉพาะ deployment ต้องตรวจเป้าหมายก่อนรัน
- `tests/` — unit, integration, การตรวจ deployment และการตรวจภาพ
- `.env.example` — ตัวอย่างตัวแปร ไม่มี credentials จริง

ฐานข้อมูลหลัก: `guild_members`, `daily_xp`, `member_events`, `xp_events`, `giveaways`, `giveaway_entries`, `giveaway_winners`, `guild_bot_settings`, `guild_rank_rules`, `guild_feature_settings`, `stream_role_assignments` และ view `member_leaderboard`

## ขอบเขตที่ยังไม่ควรอ้างว่าเสร็จแล้ว

- ยังไม่มีระบบระบุว่าใครเป็นผู้เชิญสมาชิก
- ไม่ตรวจว่าใครกำลังกดดูสตรีม ไม่ดึงภาพหรือเนื้อหาสตรีม
- n8n เป็นแนวทางต่อยอดด้วย read-only DB; ใน repository นี้ไม่ได้มี workflow n8n ที่ deploy แล้ว
- เว็บ Template Studio เพิ่มวันที่ 6 ตุลาคม 2026 สำหรับข้อความประกาศ ส่วนห้อง ยศ และสวิตช์ฟีเจอร์ยังใช้ slash commands; Login จริงต้องตั้ง OAuth Client Secret และ Redirect ให้ครบ ดู `docs/DASHBOARD.md`
- ปุ่ม “ดูไลฟ์” เป็น Discord Link มาตรฐาน ลิงก์ตรง ไม่ใช่ปุ่ม Danger สีแดง
- Docker configuration มีอยู่ แต่ Dockerfile ปัจจุบันยังไม่คัดลอก `assets/` และยังไม่ได้ทดสอบให้รองรับการ์ดล่าสุด ไม่ควรใช้เป็นเส้นทาง production โดยถือว่าผ่านแล้ว

## ผลการทดสอบและ deployment ล่าสุด

บันทึกวันที่ 4 ตุลาคม 2026 ระบุว่า build และ 19 unit tests ผ่าน รวมถึง integration tests ใน schema แยกและการตรวจภาพบน macOS/Linux การทดสอบครอบคลุม guild isolation, XP ×3/โควตา, Giveaway, การเลื่อนยศอย่างปลอดภัย และ Role สตรีมหลังรีสตาร์ต

Deployment ที่บันทึกไว้ใช้ systemd `disbot.service` บนโรงงานนรก ลง migration 006 และตรวจการลงทะเบียนคำสั่งแล้ว ค่าห้อง เกณฑ์ยศ และกติกา XP เดิมไม่เปลี่ยน รูปแบบประกาศใหม่ใช้กับเหตุการณ์ใหม่ ไม่แก้โพสต์เก่าย้อนหลัง

ข้อมูลนี้เป็นประวัติ deployment ไม่ใช่การยืนยันสถานะ production แบบสด ณ วันที่จัดทำสรุป

วันที่ 6 ตุลาคม 2026 ตรวจ TypeScript type-check/build, 19 unit tests และภาพ Chat/Talk ในเครื่อง local อีกครั้ง ผ่านทั้งหมด การจัดทำ Git ครั้งนี้ไม่ได้รัน integration กับฐานข้อมูลหรือ deploy production ใหม่
